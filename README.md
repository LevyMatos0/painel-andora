# Andora — API e painel administrativo

- **`andora-back`**: API Node.js, MySQL e avisos de contato.
- **`andora-vue`**: painel administrativo Vue/Vite.
- Site público: repositório **LevyMatos0/Andora-vue**.

Para executar no Windows, consulte [LEIA-ME-PAINEL.md](LEIA-ME-PAINEL.md).

Para publicar na Vercel e no Railway, consulte **[HOSPEDAGEM.md](HOSPEDAGEM.md)**. Cada aplicação usa sua própria pasta como Root Directory; não use a raiz deste repositório como aplicação Vite ou Node.
